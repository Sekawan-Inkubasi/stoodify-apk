# Stoodify v1.0.0 — Rilis Perdana 🚀

File installer resmi aplikasi **Stoodify** untuk perangkat Android.

Stoodify hadir sebagai asisten belajar pintar berbasis AI yang dirancang khusus untuk membantu siswa SMA/SMK sederajat menata manajemen waktu, tugas sekolah, dan rencana belajar harian secara lebih teratur dan bebas stres.

---

## 📋 Informasi Rilis

- **Versi Tag:** `v1.0.0`
- **Commit SHA:** `ab404888bfd109f51cac08f83b2b71c88570a804767e22b2993931207fe67d64`
- **Target Arsitektur:** Android ARM64 (`arm64-v8a`) & Universal
- **Ukuran:** ~19 MB
- **Karakteristik Aplikasi:** Standalone APK (100% Offline-First Embedded Bundle)

---

## ✨ Fitur Utama Stoodify

1. **Pencatatan & Pengelolaan Tugas Terintegrasi**
   - Catat tugas sekolah, PR, dan proyek kelompok secara rapi berdasarkan mata pelajaran dan tenggat waktu (*deadline*).
2. **Jadwal Belajar Cerdas Otomatis (AI Scheduling)**
   - Hasilkan rekomendasi jadwal dan sesi belajar yang dipersonalisasi sesuai ketersediaan waktu luang dan prioritas deadline tugas.
3. **Manajemen Mata Pelajaran (Mapel)**
   - Kelola daftar mata pelajaran sekolah secara dinamis untuk memudahkan pengelompokan catatan, jadwal, dan tugas.
4. **Prediksi & Rekomendasi Materi Pembelajaran AI**
   - Dapatkan saran kurasi materi dan prediksi topik pembelajaran ke depannya untuk persiapan ulangan maupun ujian.

---

## 📲 Panduan Pemasangan di HP Android

1. **Unduh Berkas APK:**
   - Unduh berkas `stoodify-v1.0.0.apk` pada bagian **Assets** di bawah rilis ini.
2. **Buka Berkas Unduhan:**
   - Buka file APK yang telah diunduh melalui *File Manager* atau notifikasi unduhan pada perangkat Android Anda.
3. **Izinkan Instalasi Sumber Tidak Dikenal:**
   - Jika muncul dialog perizinan *Install from unknown sources* / *Pasang dari sumber tidak dikenal*, pilih **Izinkan** / **Allow**.
4. **Mulai Belajar:**
   - Buka aplikasi **Stoodify**, buat akun atau masuk, dan selamat belajar!
